# Duke Java Course - Module 2 Notes

## 📌 Core Concepts
* **Class:** A blueprint or template used to create objects.
* **Object:** An instance of a class that contains state and behavior.
* **Method:** A collection of statements that perform a specific task.
* **Constructor:** A special method used to initialize objects.
